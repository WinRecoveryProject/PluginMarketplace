## Versionsforskel og kontrol

Flere offentlige Git-pakker er ældre end de installerede katalogpakker. De præcise versioner fremgår ovenfor. **Ingen installerede pakker er ændret, geninstalleret eller nedgraderet.** Vælg fortsat det officielle katalog, når du skal bevare den nyere katalogversion; installation fra en Git-post kan vælge den angivne offentlige pakke.

De seks nye App-pakker bevarer de eksisterende App-ID’er. GitHub-pakken i den offentlige kilde har desuden en valgfri GitHub Enterprise-binding. Pakkerne er derfor ikke identiske med de installerede udgaver. Katalogregistrering og App-binding beviser ikke nyt login, cloudadgang eller praktisk funktion. Ingen tilladelser, kontoforbindelser eller secrets er ændret. Budget: 0 kr.

Kilder og observerede commits er dokumenteret i [kildedata](external-plugin-collection-20261116.json). De eksterne referencer henter hos originaludgiverne; kildekode fra pakker med begrænset licens er ikke kopieret ind. De fem personlige pakker fra den første import forbliver uændrede.
