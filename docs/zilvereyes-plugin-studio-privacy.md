# Zilvereyes Plugin Studio privacy notice

Zilvereyes Plugin Studio is a local, preservation-first development tool.

The `0.2.1` package does not contain telemetry, advertising, remote analytics, an MCP server, an App binding or an OAuth flow. Its local commands read only the paths supplied by the user, return package metadata and validation results, and may create a new candidate directory only when the scaffold command is explicitly invoked. The scaffold command refuses to overwrite an existing target.

The plugin does not itself upload source files, credentials or reports. A later installation, marketplace sync, Git operation, App connection, deployment or third-party service may have its own privacy behavior and remains a separate user-authorized action governed by that service.

Reports can include local paths and manifest metadata. Review them before sharing outside the machine.
