## Rules

1. A newer Codex version is a real source observation and must be investigated, not dismissed.
2. Cache, installation, marketplace entry, editable source, upstream reference, derived candidate and historical archive remain separate states.
3. Existing sources and skills are preserved unless the user authorizes an exact deletion target.
4. Derived packages use a new name, Zilvereyes identity, compatible licensing and documented provenance.
5. Publication, installation, OAuth connection and service deployment are separate approval boundaries.
