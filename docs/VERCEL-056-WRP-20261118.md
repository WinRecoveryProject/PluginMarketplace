# Vercel 0.56.0 in WinRecoveryProject Digital

The Marketplace package `vercel@winrecoveryproject-digital` is based on [Vercel v0.56.0](https://github.com/vercel/vercel-plugin/releases/tag/v0.56.0). Version `0.56.0-wrp.1` adds Codex packaging while retaining the public OpenAI package’s 54 existing skill names and adding 12. The existing Vercel App declaration and MCP configuration are byte-for-byte identical to the previous Git package. The package retains the Apache-2.0 license and includes no vendor setup hooks.

Studio validated the manifest and skill structure. Codex loaded all 66 skills and resolved the existing Vercel App in a private catalog. The existing App returned an authenticated profile. The standalone MCP endpoint returned an OAuth challenge, so the authenticated standalone route remains unverified. No deployment, account change or paid action was part of the checks.

The risk scan flags package-manager examples that apply within an authorized project change. Its remaining credential-related signal is the Stripe Embedded Checkout client-secret callback. It is scoped to the customer’s checkout session. The guide keeps Stripe API keys on the server and session values out of logs.
