# OneDrive for Visual Studio Code

Open **MCP: List Servers** in a trusted local VS Code window and select **OneDrive**. VS Code manages sign-in and permissions through its built-in OAuth flow. The first connection from VS Code requires consent in that client. Check the returned OneDrive account and drive before opening or changing a file.

The extension registers the existing WinRecoveryProject OneDrive server over HTTPS. It shares that server with the Codex and Claude integrations. VS Code keeps its own connection. The extension has no dependencies.

Requires VS Code 1.146 or newer. [Privacy policy](https://github.com/WinRecoveryProject/PluginMarketplace/blob/main/docs/cloudstorage-privacy.md)
