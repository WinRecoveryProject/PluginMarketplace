# Local library configuration

Canonical documentation root for this private installation:

`C:\Admin\WindowsMaintainanceToolkit\Docs\Windows-Dism-Update-Docs`

This path is deployment configuration, not a universal Windows location. On another workstation, obtain the user's documentation root and update this reference. Do not fall back to cloud or whole-drive searches. The library remains external to the plugin so new findings have one maintained location. Plugin export alone does not include the library.

The project concerns private Acer and ASUS installation media, each with Home and Pro. Do not publish the library or media as part of using or validating this skill.
