# CodeRabbit Marketplace packaging adaptation

This package is maintained by WinRecoveryProject as `1.1.7-wrp.1`, based on
CodeRabbit's official 1.1.6 package at upstream commit
`35779b453cca18aa7cd3176f0bb73a8c75d11da8`. This is not an upstream CodeRabbit release.
Original CodeRabbit authorship, product name, artwork and MIT declaration remain.

Local changes: installation-specific update advice (including manual Windows
copies); skill icon copies under the skill assets directory, referenced without
parent traversal. Authentication, review scope, credit consent and host access
rules are unchanged. No Apps, MCP servers, credentials or provider connections
are added. The source lock records both upstream and adapted file hashes.
